# Controls Analysis Task

Analyze the current Controls implementation.

Do not modify code.

Create:

docs/current-controls-analysis.md

The report must include:

## Existing Navigation

List all current control categories.

## Existing Forms

List every control form currently available.

## Existing Components

Identify:

* Sidebar components
* Controls page components
* Tab components
* Form components

## Existing Routes

List all routes connected to Controls.

## Migration Mapping

For every existing control:

Current Location
→ New Location

Example:

Site Logo
→ Landing Page

Footer Manager
→ Footer

Fees
→ Cards
